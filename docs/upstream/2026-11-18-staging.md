## Ports

- GPT-6.1 Sol/Terra request restrictions, reasoning/verbosity parameters, tokenization and tool eligibility, in our server-owned generation path. Model options and vision eligibility updated. Upstream's context-size UI was removed here; context-size redesign remains in the backlog.
- Claude Fable 5.2, Sonnet/Haiku 5.5 capabilities and options; default Sonnet 5.5; retired/deprecated options updated.
- DeepSeek Flash default, legacy-setting migration, image eligibility/filtering and fallback model options. An empty discovery result preserves the fallback list.
- Reasoning tag matching ignores case on both the page and the server, including incomplete streaming blocks and their completion timing.
- Missing Claude reasoning effort leaves the thinking budget automatic.
- NanoGPT Claude caching at depth, including explicit system-prompt cache markers.
- Worldbuilding outlet entries use the same insertion ordering as other positions.
- Missing attachments leave message text unchanged rather than adding an empty separator. Our attachment reader already catches missing-file errors on the server.
- Firefox opts out of the root compositing workaround so backdrop blur keeps its transparency.
- Remove unused permissions from upstream's merge-label workflow.

## Existing replacements

- Persona conversion uses `/api/avatars/from-character`, which reads the full stored image, rather than copying a thumbnail.
- Character card writes await `lib.writeCard` and image storage and propagate failures; upstream's boolean-returning `writeCharacterData` API was removed.
- JSON/YAML imports use `imageOfCardWithoutOne`: existing cards keep their image; new cards get a default image.
- Message/reasoning editing uses the live editor. `redrawMessageText` redraws an open editor's macros without replacing its text. The old textarea/rendered-text fallback is gone.
- Missing worldbuilding position is filled in `src/world-info/candidate-resolution.js` and `src/world-info/card-book-entries.js`.
- The frontend tokenizer selection modified for ElectronHub was replaced by server tokenizer resolution. The server OpenAI model-name recognizer now accepts GPT-6.1.

## Deferred and excluded

- **Dependency security updates:** upstream changed its npm lockfile only. We use pnpm, and several corresponding locked versions are older. This integration deliberately leaves the pnpm lockfile unchanged; the security update is pending, not satisfied by the ancestry merge.
- **Image paths containing `#`/`?`:** pending adaptation across upload URLs, raw library identities, deletion and Data Maid. Copying upstream's URL encoding directly into an entity key risks creating two identities for one image. Test literal `%`, encoded traversal, containment and cleanup when implementing.
- **Custom provider setups and Profiles:** upstream's extension registry, connection transitions and managed credentials are not installed. This fork removed extension loading and connection-manager; settings/profiles are already awaiting redesign. Preserve the useful requirements (atomic endpoint/key/model changes, endpoint-bound credentials, redacted errors) in that work.
- **Overwrite snapshots:** upstream overwrites JSONL chat files; this fork uses message trees. The file-level patch is inapplicable. Review replacement/import recovery under the store-integrity backlog before calling this protection equivalent.
- **Final token-count cancellation:** the frontend final-count await was removed. Verify Stop during slow server counting separately; the upstream browser Promise race is not a port to this architecture.
- **Prompt-only regex preservation:** the extension and original frontend generation pipeline were removed. Keep this regression requirement for the saved text-rules redesign.
- TTS, expressions/VN, vectors, image generation and regex-extension maintenance target deliberately removed modules. They are not reintroduced; relevant restoration requirements belong to the existing feature-redesign backlog.
- Keyword-title localization targets the removed world-info editor template; the new worldbuilding UI is the maintained surface.
- The provider-extension guide is not added to CONTRIBUTING: it would describe extension APIs this fork does not supply.
